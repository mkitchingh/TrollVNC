Community TrollStore build of [TrollVNC](https://github.com/owngoal-dev/TrollVNC), credited to its upstream authors and contributors.

Download the `.tipa` asset and install it with TrollStore.

- Requires a working TrollStore installation.
- Tested on an iPhone 6s running iOS 15.8.4 with TightVNC Viewer on Windows.
- In TightVNC, enter `PHONE_IP::5901` (two colons) for the default port.
- Set your own full-access password in TrollVNC.
- If the wheel scrolls backwards, toggle Natural Scroll in TrollVNC.

The source archive and GPLv2 license are included with the release. See the upstream README for additional features and configuration.
